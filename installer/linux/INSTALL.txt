Run ./Filee to test the extracted app, or ./filee-cli help for the command line.

Run ./install.sh to install for the current user. It requires Python 3, creates
an application launcher and ~/.local/bin/filee, and does not require root.
Run ./install.sh --upgrade to safely upgrade an existing installation in place
without uninstalling. Your settings, presets, history, and downloaded conversion
engines are kept. Running without --upgrade refuses to overwrite an existing installation.
Run ./uninstall.sh to remove this installation and Filee-downloaded engines.
Your settings and converted files are kept. If integration cleanup fails, the
installation is kept so you can fix the error and run the uninstaller again.

Upgrade reliability and crash recovery:
The upgrade procedure prepares files on the same filesystem and replaces the
installation using atomic rename steps with an automatic rollback trap. If an error
or signal interruption occurs during the swap, the previous version is restored.
Note: While each individual directory rename is atomic in POSIX, the two-step swap
(moving the old installation aside, then moving the new version into place) is not
a single atomic transaction. In the event of uncatchable termination (SIGKILL) or
sudden hardware power loss during the brief window between steps, automatic traps
cannot execute; the previous installation is safely preserved in .backup-<pid>.
To recover manually:
- If the application directory does not exist:
    mv ~/.local/share/filee/.backup-<pid> ~/.local/share/filee/application
- If a partial or invalid application directory already exists:
    Inspect and remove or rename ~/.local/share/filee/application first, then run:
    mv ~/.local/share/filee/.backup-<pid> ~/.local/share/filee/application

The .NET runtime is bundled; its native system libraries are still required.
On Ubuntu 24.04, install the desktop and runtime dependencies with:

sudo apt-get install ca-certificates libc6 libgcc-s1 libgssapi-krb5-2 libicu74 libssl3t64 libstdc++6 tzdata zlib1g libfontconfig1 libfreetype6 libx11-6 libice6 libsm6 libxrandr2 libxkbcommon0 libxi6 libxtst6 fonts-noto-cjk python3

Other distributions use different package names. The desktop needs an X11
server (or XWayland), fontconfig, FreeType and the X11 libraries above.
X11 supports the global gesture toolbar. A native Wayland session has additional
input restrictions; use the drop window and file-manager actions if needed.
Ubuntu 24.04 is the automated build and smoke-test baseline.

rhwp and 7-Zip are bundled. Other engines are installed from Filee settings or
discovered in the system. Format support depends on available native engines.
Optional engines can require additional system libraries. In particular, calibre
may require libxcb-cursor0, libxcb-xinerama0 and other Qt/XCB dependencies.
